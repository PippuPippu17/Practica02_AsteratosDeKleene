# Práctica02 Sistema de Archivos vs. Bases de Datos

## Para compilar y correr el proyecto:

### 1. Clonar el repositorio

### 2. Dentro de la carpeta principal, seguir los siguientes comandos:

```bash
make compile
```

```bash
make run
```

### 3. Para generar la documentación usar el siguiente comando:

```bash
make doc
```

### Usar el siguiente comando entre ejecuciones del programa:

```bash
make clean
```
